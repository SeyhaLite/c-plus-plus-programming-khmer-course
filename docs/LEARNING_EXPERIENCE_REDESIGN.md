# ការរចនាបទពិសោធន៍សិក្សា

## គោលបំណង

ធ្វើឱ្យ Khmer C++ Academy មានបទពិសោធន៍រៀនជាជំហានៗ និងងាយតាមដាន ដោយយកគំនិតពី GDQuest Learn GDScript។ យើងយកគំរូអន្តរកម្មប៉ុណ្ណោះ មិនចម្លងកូដ រូបភាព ឬអត្តសញ្ញាណម៉ាករបស់គេឡើយ។

## ទិសដៅរចនា

- ពណ៌៖ បៃតងទឹកសមុទ្រ ជាពណ៌សកម្មភាព; ផ្ទៃស្រាលសម្រាប់អាន; ពណ៌មាសសម្រាប់ចំណុចសំខាន់; dark theme ប្រើពណ៌បៃតងចាស់។
- អក្សរ៖ Noto Sans Khmer សម្រាប់មាតិកាខ្មែរ, Noto Sans សម្រាប់ពាក្យបច្ចេកទេសទូទៅ និង Fira Code សម្រាប់កូដ។
- ផ្ទៃរៀន៖ ផែនទីមេរៀននៅខាងឆ្វេង, មាតិកា និងលំហាត់នៅកណ្ដាល, វឌ្ឍនភាព និងតំណទៅផ្នែកនៅខាងស្ដាំ។ នៅទូរស័ព្ទ ទាំងនេះប្ដូរទៅជាជួរឈរតែមួយ។
- វិធីរៀន៖ ស្វែងយល់ → មើលឧទាហរណ៍ → អនុវត្ត → ពិនិត្យចម្លើយ → សង្ខេប។ លំហាត់នីមួយៗនៅតែប្រើម៉ាស៊ីនពិនិត្យចម្លើយដែលមានស្រាប់។
- ភាសា៖ ស្លាកប៊ូតុង ការណែនាំ ស្ថានភាព និងមតិត្រឡប់ជាភាសាខ្មែរ។ ឈ្មោះ keyword, library, API និងកូដ C++ រក្សាដូចដើម ដើម្បីកុំបំភាន់អ្នករៀន។

## មុខងារដែលត្រូវរក្សា

- Curriculum និងលក្ខខណ្ឌដោះសោមេរៀន។
- លំហាត់ ៧ ប្រភេទ និងការច្របល់លំដាប់ជម្រើស។
- Hints, មតិត្រឡប់ជាខ្មែរ, review queue និងការពន្យល់មូលហេតុចម្លើយ។
- CodeMirror, Wandbox consent gate, XP, achievements, theme និង local progress storage។
- ស្តង់ដារ accessibility, keyboard focus និង reduced motion។

## ការផ្ទៀងផ្ទាត់

រត់ npm test, npm run typecheck, npm run build និង npm run test:e2e នៅក្នុង environment ដែលមាន Node.js និង Playwright។ ការតេស្តក្នុង browser ទំហំ desktop និង mobile ត្រូវពិនិត្យថាអក្សរខ្មែរមិនត្រូវកាត់ និងផែនទីមេរៀនអាចប្រើបានដោយ keyboard។
